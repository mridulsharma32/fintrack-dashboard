# GitHub Checklist

Before sharing the repository:

- Add a strong project description.
- Add the live demo link.
- Add screenshots of dashboard, expenses, budgets, and portfolio pages.
- Add deployment links.
- Keep `.env` files private.
- Commit `package-lock.json`.
- Do not commit `frontend/dist`, `node_modules`, `backend/venv`, or local databases.
